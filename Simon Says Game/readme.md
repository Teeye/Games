# Simon Says Game

A browser-based memory game built using HTML, CSS and JavaScript.

## Features

- Randomized game sequences
- Level progression
- User input validation
- Game-over detection
- Restart functionality

## Technologies

- HTML
- CSS
- JavaScript

## What I learned

- DOM manipulation
- Event listeners
- Arrays
- Functions
- Game state management
