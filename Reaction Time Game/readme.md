# ⚡ Reaction Time Game

A simple **Reaction Time Game** built with **HTML, CSS, and JavaScript**.

The goal is simple: wait for the screen to change, then click as quickly as possible. Your reaction time is measured in milliseconds.


## 🎮 How to Play

1. Click the **Start** button.
2. Wait for the screen to change.
3. As soon as it changes, click the screen.
4. Your reaction time will be displayed in **milliseconds (ms)**.
5. Click **Play Again** to try again and improve your score.

> ⚠️ Don't click before the screen changes!

## ✨ Features

* 🎯 Random delay before the game starts
* ⏱️ Measures reaction time in milliseconds
* 🎨 Visual feedback when the game starts
* 🔄 Play Again functionality
* 🚫 Prevents invalid clicks before the game starts
* 📱 Simple and clean interface

## 🛠️ Technologies Used

* **HTML5** — Page structure
* **CSS3** — Styling and visual effects
* **JavaScript** — Game logic, timers, events, and DOM manipulation
